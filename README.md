# Introdução à Computação

## Sobre este Repositório

Este repositório foi criado para armazenar as atividades, exercícios, projetos e materiais desenvolvidos durante a disciplina de **Introdução à Computação**.

O objetivo é manter um registro organizado do conteúdo estudado ao longo da disciplina, permitindo acompanhar a evolução do aprendizado e facilitar futuras consultas.

## Objetivo da Disciplina

A disciplina de Introdução à Computação tem como finalidade apresentar os conceitos fundamentais da área da computação, proporcionando uma base sólida para o desenvolvimento de conhecimentos mais avançados.

Entre os principais temas abordados estão:

- História e evolução da computação;
- Componentes de hardware e software;
- Sistemas operacionais;
- Internet e redes de computadores;
- Segurança da informação;
- Lógica de programação;
- Ferramentas e tecnologias utilizadas na área de Tecnologia da Informação.

## Finalidade do Repositório

Este repositório tem como objetivo:

- Armazenar atividades acadêmicas da disciplina;
- Organizar exercícios e trabalhos desenvolvidos em aula;
- Registrar o progresso do aprendizado;
- Servir como material de consulta para revisões futuras;
- Compartilhar conhecimentos e práticas realizadas durante o curso.
