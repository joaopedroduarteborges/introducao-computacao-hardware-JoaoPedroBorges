## 1. linha do tempo

A linha do tempo apresenta os principais marcos históricos da evolução das redes de computadores:

- Mainframes e terminais (décadas de 1950 e 1960);
- Criação da ARPANET (1969);
- Desenvolvimento do protocolo TCP/IP (1983);
- Surgimento da Internet comercial (década de 1990);
- Expansão das redes móveis e da Internet sem fio (2000 até os dias atuais).

## 2. Elementos Fundamentais de uma Rede

O esquema elaborado demonstra os quatro elementos básicos necessários para que a comunicação entre dispositivos aconteça.

### Emissor

É o dispositivo responsável por enviar a informação.

**Exemplo:**
- Notebook
- Smartphone

### Receptor

É o dispositivo que recebe a informação transmitida.

**Exemplo:**
- Computador
- Smart TV
- Impressora

### Meio de Transmissão

É o caminho utilizado para transportar os dados entre os dispositivos.

Exemplos:

- Cabo de rede (Ethernet)
- Fibra óptica
- Wi-Fi
- Bluetooth

### Protocolo

Conjunto de regras que define como os dispositivos devem se comunicar.

Exemplos:

- TCP/IP
- HTTP
- HTTPS
- FTP

## 3. Classificação das Redes

As redes podem ser classificadas conforme sua área de cobertura.

| Tipo | Descrição | Exemplo |
|------|-----------|----------|
| **PAN** | Rede pessoal de curto alcance | Bluetooth entre celular e fone de ouvido |
| **LAN** | Rede local | Rede doméstica ou laboratório de informática |
| **MAN** | Rede metropolitana | Rede de uma universidade ou prefeitura |
| **WAN** | Rede de longa distância | Internet |

# Conclusão

A evolução das redes de computadores permitiu que a comunicação entre pessoas e dispositivos se tornasse cada vez mais rápida, eficiente e acessível. Atualmente, diferentes tipos de redes atendem desde pequenas conexões pessoais até a infraestrutura global da Internet.

Além disso, compreender os elementos fundamentais da comunicação em rede e os protocolos utilizados é essencial para entender o funcionamento dos sistemas computacionais modernos.
